# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good faith, critique claims and code rather than people,
and accept that a well-argued counterexample is a contribution, not an attack.

Report unacceptable behaviour privately to the maintainers through the repository's
private security advisory form (Security tab → Report a vulnerability) and mark it as a
conduct report. Reports are handled confidentially. Maintainers may remove comments,
issues or contributions that violate this code and may restrict participation.
