# Scripted example

These files are exact copies of the outputs of a scripted smoke demonstration produced on
4 October 2026. They contain **no real model results**. Start with [REPORT.md](REPORT.md),
inspect the [metric values](metrics.json), or examine [candidate outcomes](group_outcomes.csv).

The SVG preview in the README is generated from this JSON; see [design and regeneration](../DESIGN.md).
The example can be read without running Python. Use `python -m rbs quickstart` to generate a
fresh demonstration of your own.
